# HTML5 New Tags and Attributes Demo

This project demonstrates the use of **HTML5 semantic elements, multimedia tags, and new form attributes**. It highlights how modern browsers can handle video, audio, canvas graphics, and enhanced forms without relying on external plugins.

---

## 📂 Project Structure

The webpage is organized into the following sections:

- **`<header>`**  
  Displays the title and description of the demo.

- **Video Section (`<video>`)**  
  Embeds a sample video with native playback controls.

- **Audio Section (`<audio>`)**  
  Embeds a sample audio file with native playback controls.

- **Canvas Section (`<canvas>`)**  
  Demonstrates drawing graphics using JavaScript.  
  Example: a blue rectangle rendered on the canvas.

- **Sidebar (`<aside>`)**  
  Provides contextual information about how HTML5 replaced external plugins like Flash, Silverlight, and Java Applets.

- **Form Section (`<form>`)**  
  Showcases new HTML5 form attributes:
  - `placeholder` → Displays hint text inside input fields.
  - `required` → Ensures mandatory fields are filled before submission.
  - `autofocus` → Automatically focuses on the first input field when the page loads.

- **`<footer>`**  
  Contains copyright.

---

## 🖥️ Features Demonstrated

- **Multimedia Support**  
  - `<video>` and `<audio>` tags for native playback.  
  - No need for external plugins.

- **Canvas Graphics**  
  - `<canvas>` element for 2D drawing.  
  - JavaScript used to render a blue rectangle.

- **Enhanced Forms**  
  - Built-in validation with `required`.  
  - Improved usability with `placeholder` and `autofocus`.

- **Semantic Elements**  
  - `<header>`, `<section>`, `<aside>`, `<footer>` for better structure and accessibility.

---

## 🚀 How to Run

1. Clone or download the project.
2. Place `sample.mp4` and `sample.mp3` in the same directory as `index.html`.
3. Open `index.html` in any modern web browser.
4. Explore:
   - Play the video and audio.
   - View the canvas drawing.
   - Test the form validation.
