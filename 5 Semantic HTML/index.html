Quick Tips

  • Use <header> for top sections
  • Use <nav> for navigation links
  • Use <main> for the main content of the page
  • Use <section> to group related content
  • Use <article> for independent, reusable content
  • Use <aside> for side or supplementary content
  • Use <footer> for closing or copyright information
  • Use <figure> for images or media content
  • Use <figcaption> to describe a figure
