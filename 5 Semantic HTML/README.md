# Semantic HTML Website Example

This project demonstrates the use of **semantic HTML5 elements** to build a simple, well-structured, and accessible webpage. Semantic elements clearly describe their meaning in a human- and machine-readable way, improving readability, accessibility, and SEO.

---

## 📂 Project Structure

The webpage is divided into the following semantic sections:

- **`<header>`**  
  Contains the site header with a title and tagline.

- **`<nav>`**  
  Navigation bar with links to different sections of the page.

- **`<main>`**  
  The main content area of the website, including:
  - **`<section>`**: Groups related content (Tutorials, Resources).
  - **`<article>`**: Independent, reusable pieces of content (tutorials).
  - **`<aside>`**: Sidebar with supplementary information (quick tips).

- **`<footer>`**  
  Bottom section with contact information and copyright.

---

## 🖥️ Features

- Demonstrates **semantic HTML tags** (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`).
- Includes **tutorial articles** explaining semantic HTML and accessibility.
- Provides **quick tips** for using semantic elements correctly.
- Lists **useful resources** for learning web development.
- Responsive design enabled with `<meta name="viewport">`.

---

## 🚀 How to Use

1. Clone or download the project.
2. Open the `index.html` file in any modern web browser.
3. Explore the structure:
   - Header and navigation at the top.
   - Tutorials and resources in the main content.
   - Sidebar with quick tips.
   - Footer with contact details.

## 📖 Learning Goals

This project helps you understand:
- Why semantic HTML improves accessibility and SEO.
- How to structure a webpage using semantic elements.
- The difference between **structural tags** (`section`, `article`) and **supplementary tags** (`aside`, `footer`).

---

## 🛠️ Example Tags Used

- `<header>` – Defines the top section of the page.  
- `<nav>` – Groups navigation links.  
- `<main>` – Contains the primary content.  
- `<section>` – Groups related content.  
- `<article>` – Represents standalone content.  
- `<aside>` – Provides supplementary information.  
- `<footer>` – Contains closing information.
