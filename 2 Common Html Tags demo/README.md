# Common HTML Tags Demo

This repository demonstrates the **basic building blocks of HTML**:  
- Headings (`<h1>`–`<h4>`)  
- Paragraphs (`<p>`)  
- Images (`<img>`)  
- Links (`<a>`)

It is designed as a simple learning resource for beginners to see how these tags work in a real browser.

---

## 📖 Features

### 1. Headings
- `<h1>`: Main page title
- `<h2>`, `<h3>`, `<h4>`: Subsections with decreasing importance

### 2. Paragraphs
- `<p>`: Blocks of text
- Inline formatting with `<strong>` (bold) and `<em>` (italic)

### 3. Images
- `<img src="..." alt="...">`: Embeds images
- Demonstrates both local image (`Tree.png`) and external placeholder image

### 4. Links
- `<a href="...">`: Creates hyperlinks
- Example of a normal link
- Example of a link that opens in a new tab (`target="_blank"` + `rel="noopener noreferrer"`)
