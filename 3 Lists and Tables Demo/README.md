## 📄 Lists and Tables Demo (HTML)

### 📝 Description

This project demonstrates how to create **lists** and **tables** using basic HTML elements.
It is useful for beginners who want to understand how to organize content on a webpage.

---

### 🚀 Features

* Uses **unordered lists** (`<ul>`) for items without order
* Uses **ordered lists** (`<ol>`) for step-by-step instructions
* Uses **tables** (`<table>`) to display structured data
* Includes a **responsive viewport meta tag**
* Clean and simple HTML structure

---

### 🧱 HTML Elements Used

#### 📌 Lists

* `<ul>` – Unordered list
* `<ol>` – Ordered list
* `<li>` – List item

#### 📌 Tables

* `<table>` – Table container
* `<tr>` – Table row
* `<th>` – Table heading
* `<td>` – Table data
* `<caption>` – Table title
