# 📘 HTML Components Guide

This project introduces the **fundamental components of HTML** and demonstrates how to build structured, accessible, and modern web pages.

---

## 📂 Topics Covered

### 1. Basic Structure of an HTML Document
- Understanding `<!DOCTYPE html>`
- Using `<html>`, `<head>`, and `<body>` tags
- Adding metadata and titles

### 2. Common HTML Tags and Their Usage
- Headings (`<h1>` – `<h6>`)
- Paragraphs (`<p>`)
- Images (`<img>`)
- Links (`<a>`)

### 3. Creating Lists and Tables
- Ordered lists (`<ol>`) and unordered lists (`<ul>`)
- Tables with `<table>`, `<tr>`, `<td>`, `<th>`

### 4. Using HTML Forms for User Input
- Input fields (`<input>`)
- Labels (`<label>`)
- Buttons (`<button>`)
- Attributes like `required`, `placeholder`, `autofocus`

### 5. Semantic HTML
- Using appropriate tags to convey meaning and structure:
  - `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`

### 6. HTML5 New Tags and Attributes
- Multimedia: `<video>`, `<audio>`
- Graphics: `<canvas>`
- Form enhancements: `required`, `placeholder`, `autofocus`
- Improved semantics for accessibility and SEO

---

## 🚀 How to Use
1. Clone or download the repository.
2. Open the `index.html` file in a browser.
3. Explore examples of each HTML component.
4. Modify and experiment with tags to deepen your understanding.

---

## 🎯 Learning Goals
- Build a strong foundation in HTML.
- Learn how to structure documents with semantic elements.
- Understand modern HTML5 features for multimedia and forms.
- Practice creating accessible and user‑friendly web pages.
